# Hardware Resources for SSMS Prototype

## 1. Central Server (for SSMS)

- Raspberry Pi 4 (8GB RAM model)
- MicroSD card (64GB or larger)
- Power supply for Raspberry Pi
- Ethernet cable for network connection

## 2. Simulated Smart Meters (for Houses)

- 3-5 NodeMCU ESP8266 boards
- Micro USB cables for power and programming
- Breadboards for prototyping

## 3. Development Computer

- Laptop or desktop computer for coding and testing
- Must be capable of running Android Studio and/or Xcode for mobile app development

## 4. Mobile Devices (for UMA testing)

- Android smartphone
- iPhone (if developing for iOS)

## 5. Network Equipment

- Wi-Fi router (for connecting all devices)

## 6. Power Monitoring (optional, for realism)

- Current sensor modules (e.g., ACS712)
- Voltage sensor modules
- Some resistive loads (e.g., light bulbs) to simulate power consumption

## 7. Display (optional)

- Small LCD display for Raspberry Pi (e.g., 7" touchscreen)

## 8. Accessories

- Jumper wires
- USB hub (for connecting multiple devices to Raspberry Pi)
- Power strip for plugging in all devices

Note: This hardware list assumes you'll be simulating the solar panels and inverter in software. If you want to include actual solar components for a more realistic prototype, you'd need additional specialized equipment.
