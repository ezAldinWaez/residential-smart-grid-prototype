# Solar System Management System

## Overview

A smart system that distributes power harvested from a system of solar panels to empower an entire building, a system to manage the distribution of said power between each house in the building. The management includes smart breaking when the power used exceeds the allocated, but allows for overusage when others underuse with priority for the underusing.

## Features

- Coupled with an android client for monitoring and management options
- Decentralized management vs Simplicity
- Live overview of power usage and visualizations
