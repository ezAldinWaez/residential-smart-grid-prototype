 # Outline

## Phase 1: Skeleton Software Simulation

First, we want a base for the Solar System simulation, a base for the Management, and a base for the Clientele Simulation.

So, first to decide a Framework for each. For example, we may want to use event-based simulation for the Clientele, and maybe some data-based simulation for the Solar System.

1. Research and decide on the Framework for the Solar System simulation and that for the Clientele simulation.
2. Implement the base Framework for each and set basic simulation.
3. Implement basic logic for Management and link with the simulations.

## Phase 2: Incremental Feature Implementation

It's a cycle of deciding on a feature and implementing it. Features are decided on by council. Each feature dictates its own method of planning and dishing out tasks for each.
